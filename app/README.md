# Application Directory

This directory stores the GUI deployment code developed in **Phase 4**.

Architecture:
- Built with Streamlit for intuitive, interactive shop-floor decision support.
- Modules:
  - Telemetry input simulator (temperature, torque, tool wear, rotational velocity sliders).
  - Real-time failure risk gauge and operational warning banner.
  - Global Explainable AI panel (SHAP feature rankings, PDP marginal curves).
  - Local Diagnostic Workbench (SHAP waterfall decompositions, LIME rule explanations).
  - Multi-Modal Demos (thermal crack detection Grad-CAM, technician maintenance log token attributions).
