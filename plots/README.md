# Plots Directory

This directory stores generated high-resolution visualizations in PNG format.

Phase 1 Deliverables:
- `class_distribution.png`: Bar plot illustrating the ~3.8% failure class imbalance.
- `correlation_heatmap.png`: Pearson correlation matrix among numeric telemetry features and failure target.
- `missing_values.png`: Feature-wise missing value frequency chart.
- `feature_distributions.png`: Multi-panel histograms and KDE curves for telemetry signals segmented by machine failure.
